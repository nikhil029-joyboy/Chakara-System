NINJA SYSTEM v3.7 — RASENSHURIKEN + CHIDORI VISUAL REFINEMENT

This release builds on the uploaded v3.3 project. It keeps the existing jutsu, dual-hand controls, combo progression, rank/XP, and mastery systems.

NEW IN v3.7
- Refined Rasenshuriken: a dense blue Rasengan-style orb with a four-blade wind shuriken clearly placed inside it.
- The four-blade shuriken rotates continuously and has a subtle individual blade pulse for better readability.
- Refined Chidori: denser, longer branching blue lightning streams with additional electrical particles. It remains a directional lightning effect, not a sphere.
- Improved desktop layout: larger camera panel on the left and technique selection/status content beside it.
- Updated version labels to v3.7.

PRESERVED FEATURES
- MediaPipe hand tracking and independent dual-hand jutsu activation.
- Fire Style, Rasengan, Chidori, and Rasenshuriken.
- Dual-Hand Rasengan Fusion, Chakra Shield, Advanced Chakra Aura, Ultimate Chakra Mode, and Ultimate Chakra Blast.
- Combo System, Shinobi Rank & XP, and saved Jutsu Mastery progression.
- Existing gesture controls: show an open palm, make a fist to activate, and open the hand to deactivate.
- Naruto hand-seal recognition remains removed.

CONTROLS
1. Open the project in VS Code using Live Server.
2. Press INITIALIZE SYSTEM and allow webcam access.
3. Select a technique from the right-side technique panel.
4. Show an open palm, then make a fist to activate the selected technique.
5. Open your hand to deactivate it.

INSTALLATION
1. Keep a backup of your current v3.3 folder.
2. Extract NINJA_SYSTEM_v3_4_complete.zip.
3. Open the NINJA_SYSTEM_v3_4 folder in VS Code.
4. Start index.html using Live Server.

VALIDATION
JavaScript syntax and ZIP integrity are checked. Browser webcam tracking, visual appearance, and performance still need to be tested on your computer. XP and mastery progress remain saved in the browser's localStorage.
